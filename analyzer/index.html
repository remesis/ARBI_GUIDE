LOCAL ARBITRATION ANALYZER

Drop in an EE.log

All log parsing and report generation happen locally in your browser. Only the reduced SolNode spawn counts and coordinates needed for future aggregate metrics are submitted; no player names, raw log lines, or unrelated data are uploaded.

This tool analyzes your Warframe EE.log (which is meant to be player-readable) and returns useful insight about your Arbitration efficiency. Multiple Arbitration missions become separate entries in the run list.

A discrepancy between EE.log numbers and in-game stats is expected. The game's UI is known to misreport kills due to client/server desync. This tool considers the raw EE.log data the true data.
